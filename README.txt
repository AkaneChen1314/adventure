深境冒險｜職業戰鬥 RPG
版本：v2.7（GitHub Pages／手機快取修正版）

開啟方式
1. 解壓縮整個資料夾。
2. 直接雙擊 index.html，即可離線遊玩。
3. index.html、style-v2.7-mobile-safe.css、game-v2.7-mobile-safe.js 必須保留在同一層。
4. 開啟後左上角應顯示「ABYSSAL ADVENTURE · v2.7」；若仍顯示 v2.1，代表 GitHub Pages 還在發布舊的首頁。
5. 部署到 GitHub Pages 時，請閱讀 DEPLOY_GITHUB.txt，並把檔案放在 Pages 發布來源的根目錄。

主要系統
- 六種職業：騎士、盜賊、法師、獵人、祭司、狂戰士。
- 開場職業卡會列出生命、攻擊、防禦、爆擊、速度與職業資源。
- 「這個遊戲在玩什麼？」可開啟完整遊戲目標與系統說明。
- 每個職業有獨立資源、三種專屬技能與不同基礎能力。
- 普通攻擊之外新增猛力重擊、破勢斬、防禦架勢與集中蓄力，共 8 種攻擊與戰術選擇。
- 破勢斬可針對敵人的蓄力重擊與防禦意圖進行中斷，讓敵人情報真正影響戰術。
- 連續攻擊且沒有受到實際傷害會累積連擊，最高 5 層、增加 20% 傷害。
- 戰鬥中使用藥水會消耗一回合，不再能無限制免費補血或解除異常。
- 電腦支援數字鍵 1～4 使用基本／職業技能，Q～R 使用四種共通戰術。
- 等級、經驗值、距離升級所需經驗會即時顯示。
- 每種怪物掉落對應素材；素材與金幣可在商店製作裝備。
- 六個一般職業各有 5 把專屬武器與 5 件專屬盔甲，共 60 件裝備。
- 裝備分為普通、稀有、史詩、傳說、彩耀五階，階級之間的攻擊、生命與防禦差距已明顯拉大。
- 彩耀裝備使用流動彩色外框與底色；穿上後「目前裝備」欄位也會同步顯示彩耀效果。
- 傳說與彩耀武器附帶吸血；高階盔甲附帶抗毒，彩耀盔甲另外提供傷害減免。
- 穿上裝備後，「目前裝備」欄位的外框、底色、圖示與標籤也會同步顯示稀有度。
- 合成清單會顯示裝備效果；強化時會顯示強化前後數值與成功率。
- 武器與盔甲最高可強化到＋9；攻擊、生命、防禦、暴擊、速度、吸血、抗毒與減傷等現有屬性都會同步提升。
- 強化失敗不降級、不損壞；強化前後預覽會列出全部會變動的屬性。
- 菁英挑戰每次使用後需再前進隨機 3～5 區，不能連續重複挑戰。
- 每 5 區會遇到一般首領，每 50 區會出現更強的傳說級大型 Boss。
- 菁英、一般首領與 50 層大型 Boss 均有不同的戰鬥背景效果。
- 敵人情報會標示防禦減傷、特殊能力與擊殺倒數，無需自行猜測。
- 怪物可施加中毒、燃燒、流血與虛弱；異常傷害會逐回合衰減。
- 玩家狀態固定顯示在生命值上方；滑鼠移入或手機點擊可查看效果說明。
- 手機與窄版畫面的狀態說明改為跨欄全域浮層，不會被角色欄或戰鬥欄裁切。
- 敵人的普通攻擊、重擊與防禦意圖都能開啟說明提示；暫時移除敵人的破防攻擊。
- 商店可購買生命、資源、解毒、滅火、止血、解除虛弱與完全淨化藥水。
- 商店可使用「全部／藥水／武器／盔甲」快速分類，背包也能分開查看武器與盔甲。
- 商店分類會嚴格只顯示選定類型，分類列不再被長清單壓縮。
- 戰鬥時商店與強化頁會改為鎖定說明，回到探索休息區後自動恢復。
- 商店、背包、戰報與提示框的捲軸統一為深藍色，不再出現白色原生捲軸。
- 怪物只會掉落生命藥水或資源藥水；其他異常解除藥水為商店限定。
- 戰鬥補給列已改為單一「使用藥水」按鈕，避免戰鬥畫面長時間被大量道具占滿。
- 按下後技能與戰術會暫時收起，改為顯示所有藥水及完整效果說明。
- 每回合可選擇 1～3 種不同藥水，同一種藥水每回合最多 1 瓶；確認後整批只消耗 1 回合。
- 未持有或目前沒有可作用效果的藥水會明確標示並停用，背包仍不提供戰鬥中免費使用。
- 藥水選單改為自適應浮層：桌機依寬度自動增加欄數，矮螢幕只捲動藥水清單，取消與確認固定顯示。
- 手機版使用底部面板，保留安全區並加大操作按鈕；取消改為深色高對比樣式，避免白底白字。
- 開場新增密碼限定的「上帝模式」，提供測試與爽玩用的極高能力、金幣、素材與藥水。
- 上帝模式調整為 99999 生命、99999 神力與 999 攻擊，舊版上帝模式存檔也會自動更新。
- 上帝模式背包總數超過 999 時顯示為「999+」，實際物品數量不會減少。
- 部分骷髏與 Boss 有倒數詛咒，期限後每次命中都會追加最大生命百分比傷害。
- 戰報固定在右側面板內，最新紀錄置頂，舊紀錄可在框內捲動查看。
- 手機版戰術卡可橫向滑動，技能改為較大的雙欄觸控按鈕；桌機版則完整顯示快捷鍵與說明。
- 進度會自動儲存在瀏覽器中。
