深境冒險｜職業戰鬥 RPG

開啟方式
1. 解壓縮整個資料夾。
2. 直接雙擊 index.html，即可離線遊玩。
3. index.html、style.css、game.js 必須保留在同一層。

主要系統
- 六種職業：騎士、盜賊、法師、獵人、祭司、狂戰士。
- 每個職業有獨立資源、三種技能與不同基礎能力。
- 普通攻擊可恢復職業資源；技能有消耗與冷卻時間。
- 等級、經驗值、距離升級所需經驗會即時顯示。
- 每種怪物掉落對應素材；素材與金幣可在商店製作裝備。
- 武器與盔甲最高可強化到＋9；失敗不降級、不損壞。
- 每 5 區會遇到首領，菁英挑戰有更高素材與強化石收益。
- 進度會自動儲存在瀏覽器中。
