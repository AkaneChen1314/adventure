深境冒險 v2.7｜GitHub Pages 部署方式

你手機截圖顯示的是 v2.1，代表手機收到 GitHub Pages 上的舊版 index.html，並不是手機版功能被 CSS 隱藏。

請依照以下方式更新：

1. 解壓縮本壓縮檔。
2. 打開 GitHub 上負責 hen1314.github.io 的儲存庫。
3. 進入 Settings → Pages，確認目前發布來源是哪一個分支與資料夾：
   - 例如 main / (root)
   - 或 main / docs
4. 把以下檔案直接放到該發布資料夾的最外層，不要再包一層 abyss-adventure-rpg 資料夾：
   - index.html
   - style-v2.7-mobile-safe.css
   - game-v2.7-mobile-safe.js
   - .nojekyll
   - version.txt
5. 確認新版 index.html 已取代原本顯示 v2.1 的 index.html，然後 Commit changes。
6. 到 GitHub 的 Actions／Pages 等待部署完成；GitHub Pages 更新可能需要數分鐘。
7. 手機第一次請使用以下網址開啟：
   https://hen1314.github.io/?build=27
8. 左上角必須顯示「ABYSSAL ADVENTURE · v2.7」。若仍顯示 v2.1：
   - 用無痕模式開啟上述網址。
   - 或清除 hen1314.github.io 的網站資料後再開。
   - 再檢查 Settings → Pages 是否發布到你剛才上傳檔案的分支／資料夾。

為什麼這版比較不容易載入舊檔：
- CSS 與 JavaScript 已改用全新檔名，不會與舊版 style.css、game.js 共用快取。
- index.html 加入禁止沿用舊快取的標記。
- 使用相對路徑，可同時支援使用者首頁與專案子路徑。

存檔說明：
- 遊戲仍沿用原本的瀏覽器存檔鍵，更新同一網址後可繼續舊進度。
- 無痕模式只適合確認版本；正式遊玩請回到一般模式，才不會關閉後遺失無痕存檔。
